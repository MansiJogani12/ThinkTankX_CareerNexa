# PrepWise - Detailed Feature Specification

This document provides a highly detailed breakdown of every core feature in the PrepWise application (Student/Candidate Career OS). For each module, it explicitly defines the **Inputs** (what the system takes) and **Outputs** (what the system returns).

---

## 1. AI Mock Interview Module

This module simulates a real technical or behavioral interview.

* **Feature:** Dynamic Question Generation
  * **Input (kya leta hai):** 
    * User's target Job Role (e.g., "Frontend Developer").
    * Experience Level (e.g., "Junior").
    * Specific Skills (e.g., "React, Next.js").
  * **Output (kya deta hai):** 
    * A curated list of 5-10 tailored interview questions (a mix of technical, behavioral, and situational).

* **Feature:** Real-time Answer Recording
  * **Input (kya leta hai):** 
    * User's webcam video feed.
    * User's microphone audio feed.
  * **Output (kya deta hai):** 
    * A locally recorded audio/video blob.
    * A live transcript of the user's spoken answer (Speech-to-Text).

* **Feature:** AI Answer Evaluation
  * **Input (kya leta hai):** 
    * The specific interview question being asked.
    * The text transcript of the user's answer.
  * **Output (kya deta hai):** 
    * **Score (0-10):** A quantitative rating of the answer.
    * **Feedback:** Constructive criticism highlighting what the user missed or did well.
    * **Ideal Response:** A generated sample of the perfect way to answer that specific question.

## 2. Resume Builder & Parser

This module helps users extract data from their existing resumes and build/export highly optimized new ones.

* **Feature:** AI PDF Resume Parser
  * **Input (kya leta hai):** 
    * A raw PDF file of the user's existing resume.
  * **Output (kya deta hai):** 
    * A highly structured JSON object containing:
      * `technicalSkills` (e.g., ["React", "Node.js"])
      * `softSkills`
      * `toolsFrameworks`
      * `programmingLanguages`
      * `experience` (Array of past jobs with dates and descriptions)
      * `education`
      * `projects`

* **Feature:** Deterministic ATS Scoring
  * **Input (kya leta hai):** 
    * The structured JSON extracted from the parsed resume.
  * **Output (kya deta hai):** 
    * **Overall ATS Score (0-100):** A deterministic, math-based score (no AI hallucination).
    * **Score Breakdown:** Individual scores for `Formatting`, `Keywords`, `Structure`, and `Readability`.
    * **Actionable Feedback:** Specific advice on how to improve the score (e.g., "Add more quantifiable metrics to your experience section").

* **Feature:** Dynamic Editing & Multi-Format Export
  * **Input (kya leta hai):** 
    * The structured JSON resume data.
    * User's real-time text edits and layout drag-and-drop actions.
    * Selected export format (PDF, DOCX, or LaTeX).
  * **Output (kya deta hai):** 
    * A visually formatted, printable resume document generated on the fly in the requested format.

## 3. Job Matcher & Aggregator

This module finds relevant jobs for the user and ranks them based on their exact skills.

* **Feature:** LinkedIn Live Job Scraper
  * **Input (kya leta hai):** 
    * Search query (e.g., "React Developer").
    * Preferred Location (e.g., "Bangalore, India").
  * **Output (kya deta hai):** 
    * A real-time list of public job postings from LinkedIn including: Job Title, Company Name, Location, Description snippet, and the direct Application URL.

* **Feature:** Deterministic Job Matching & Skill Gap Analysis
  * **Input (kya leta hai):** 
    * The user's parsed skills array (e.g., `["React", "CSS"]`).
    * The target Job Description (text or extracted requirements).
  * **Output (kya deta hai):** 
    * **Match Score (0-100):** How well the user fits the job based on exact keyword intersections.
    * **Matched Skills:** Array of skills the user *has* that the job *needs* (e.g., `["React"]`).
    * **Missing Skills:** Array of skills the job *needs* that the user *lacks* (e.g., `["Docker", "AWS"]`).

* **Feature:** Learning Resource Injector
  * **Input (kya leta hai):** 
    * The array of `Missing Skills` generated by the Job Matcher.
  * **Output (kya deta hai):** 
    * Direct links to curated learning materials (YouTube crash courses, official documentation) for each missing skill so the user can immediately learn what they lack.

* **Feature:** Interactive Map View
  * **Input (kya leta hai):** 
    * The list of scraped jobs and their text-based locations (e.g., "Pune", "Mumbai").
  * **Output (kya deta hai):** 
    * A Leaflet.js interactive map plotting pins for every job, sorted visually by proximity to the user's preferred city.

## 4. General Platform (Dashboard)

* **Feature:** Candidate Readiness Dashboard
  * **Input (kya leta hai):** 
    * Historical data (Past mock interview scores, ATS resume scores, average Job Match scores).
  * **Output (kya deta hai):** 
    * A holistic "Overall Readiness Score".
    * Visual charts and recent activity logs to track progress over time.

## ⚠️ Known Issues

* **LinkedIn Rate Limiting:** 
  * *Input Problem:* Too many real-time scrape requests.
  * *Output Result:* LinkedIn blocks the IP (HTTP 429), resulting in 0 jobs found temporarily.
* **Map Geocoding Accuracy:** 
  * *Input Problem:* A job location is a highly specific street address or minor town.
  * *Output Result:* The map cannot plot the pin accurately due to missing coordinates in the hardcoded tech-hub database.
